# A Little Place to Feel Better

A small, quiet browser game: a garden, a cat, flowers, stars and kind notes. No timers, nothing to finish.

## Files
- `index.html` - the page
- `style.css` - styling
- `data.js` - flowers, decorations, notes and cat lines (easy to edit)
- `game.js` - game logic

## Run on GitHub Pages
1. Create a new repository on GitHub and upload these files to the root.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. After a minute the game is live at `https://<your-username>.github.io/<repo-name>/`.

## Run locally
Open `index.html` in a browser. No build step needed.
